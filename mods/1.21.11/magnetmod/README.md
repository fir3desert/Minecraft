# MagnetMod

MagnetMod is a Minecraft utility mod that adds a simple magnet effect and a virtual chest system.

## Commands

| Command | What it does |
| --- | --- |
| `/magnet` | Deactivates the magnet if it is active |
| `/magnet <radius>` | Activates the magnet with a radius from 1 to 6 blocks for 10 minutes |
| `/chest` | Opens your virtual chest |

## Magnet behavior

- The magnet can be activated with a radius between 1 and 6 blocks.
- The effect lasts 10 minutes once enabled.
- Using `/magnet` without a value disables the active magnet.

## Virtual chest

- Each stack in the virtual chest has an expiration time of 1 hour.
- This allows the chest to act as a temporary storage system for items.

## Summary

MagnetMod combines a timed magnet pickup feature with a virtual chest system, making it useful for quick collection and temporary item storage in-game.
