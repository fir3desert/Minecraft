# GUITables

GUITables is a utility mod that lets you open crafting, anvil, brewing, smithing, and other work tables directly from a command.

## Commands

| Command | Table | Type |
| --- | --- | --- |
| `/guitables crafting` | Crafting Table | Virtual |
| `/guitables enderchest` | Ender Chest | Real |
| `/guitables anvil` | Anvil | Virtual |
| `/guitables stonecutter` | Stonecutter | Virtual |
| `/guitables brewing` | Brewing Stand | Virtual |
| `/guitables grindstone` | Grindstone | Virtual |
| `/guitables cartography` | Cartography Table | Virtual |
| `/guitables loom` | Loom | Virtual |
| `/guitables smithing` | Smithing Table | Virtual |
| `/guitables trash` | Trash | Utility |

## What it does

This mod makes it easy to access useful crafting and utility tables from anywhere, without needing to place blocks in the world.

It includes a wide set of virtual workstations plus a trash option for quickly clearing items.

## Summary

A simple quality-of-life mod for opening work tables and utility menus anywhere in the world.
