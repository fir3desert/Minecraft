# FlyMod

FlyMod is a simple mod that lets you activate flight in Minecraft with a single command.

## Command

Type this in chat:

```text
/fly
```

When used, flight is enabled for 30 minutes.

## Duration

- Flight lasts exactly 30 minutes from activation.
- Once the timer ends, flight is automatically disabled.

## Notes

- This is designed to be a very simple command-based fly system.
- It is intended to be quick to use and easy to understand.
- The flight timer is fixed to 30 minutes.

## Purpose

The mod is built around a minimal and convenient experience:

- one command
- fixed 30-minute duration
- automatic deactivation when the timer ends

## Usage

- Use `/fly` to enable flight.
- After 30 minutes, the effect ends automatically and flight is disabled.

## Note

This mod is intended for straightforward use: everything is controlled with `/fly`, with a fixed 30-minute flight duration and no extra setup required.
