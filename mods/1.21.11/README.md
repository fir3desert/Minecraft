# Mods Collection

This folder contains several Minecraft mods I have developed for a custom server setup. Each mod focuses on a different gameplay utility, command, or quality-of-life feature.

## Included mods

- FlyMod — simple command-based flight with a fixed 30-minute duration.
- PlayerStats — player statistics, personal progress tracking, and category-based top rankings.
- AFKMod — AFK toggle behavior with protective effects and automatic deactivation when the player moves.
- MagnetMod — timed magnet pickup radius and a virtual chest with temporary item stack expiration.
- GUI Tables — GUI-focused utility for table-based interfaces.
- CratesMod — a crate/loot-system concept that is still unfinished.

## Status

These mods are part of the same collection and are in different stages of development. CratesMod is the one currently marked as incomplete.

## Summary

The collection is centered around practical server-side features and small gameplay helpers, with a mix of utility mods, progression tracking, and experimental systems.
