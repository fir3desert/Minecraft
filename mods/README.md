# Mods

This folder contains the custom Minecraft mods developed for this project.

## Purpose

These mods are grouped by Minecraft version and include utility, gameplay, and server-quality-of-life additions.

## Available versions

- [1.21.11](./1.21.11/README.md) — current mod collection for Minecraft 1.21.11

## Included mod categories

The active collection includes mods such as:

- FlyMod
- PlayerStats
- AFKMod
- MagnetMod
- GUI Tables
- CratesMod

## Summary

This directory is the main landing page for the custom mod collection used in this Minecraft setup.
