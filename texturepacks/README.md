# Texture Packs

This folder contains the custom Minecraft texture packs used by this project.

## Purpose

The texture packs are organized by Minecraft version and provide visual changes for specific blocks, items, or other game assets.

## Available versions

- [1.21.11](./1.21.11/) — texture packs for Minecraft 1.21.11

## Included texture packs

### SoftMagma

SoftMagma changes the magma block texture to provide a softer visual style while preserving the original Minecraft resource-pack structure.

- [Pack directory](./1.21.11/SoftMagma/)
- [Download ZIP](./1.21.11/SoftMagma.zip)

## Installation

1. Download the ZIP file for the Minecraft version you are using.
2. Open Minecraft and go to **Options → Resource Packs**.
3. Select **Open Pack Folder**.
4. Place the downloaded ZIP file in that folder.
5. Enable the texture pack in Minecraft.
