# Scripts

This folder contains the scripts I use to administer and manage the Minecraft server.

## Purpose

These scripts are intended to automate common server-management tasks, such as firewall configuration, service maintenance, and operational checks.

## Included scripts

- [ufw](./ufw/README.md) — firewall rules for allowing specific IPs while keeping the server locked down by default

## Summary

This directory is the main collection of server administration scripts used to keep the Minecraft environment operational and secure.
